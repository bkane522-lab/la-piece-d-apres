# Déploiement Vercel

1. Connecter le dépôt `la-piece-d-apres` à Vercel.
2. Framework : Next.js, branche de production : `main`.
3. Ajouter les quatre variables de `.env.example` dans Vercel.
4. Lancer un nouveau déploiement depuis le dernier commit.
5. Dans Supabase Auth > URL Configuration, ajouter l’URL Vercel de production et l’URL de callback `/auth/callback`.
6. Tester inscription, confirmation email, connexion, création d’un projet, contact et accès admin.
